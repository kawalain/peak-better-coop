# A Rescue Carry stacks on the Rider's back

A passed-out scout's time runs out unless someone carries them, and every
Carrier's one carry is held by its Rider for the whole Run, so a party of Pairs
could only watch a passed-out scout die (ADR 0002 forbade nested carries). Now
a Shared Body rescues by putting the Rescued on its Rider's back: the Rider's
character carries the Rescued with the game's own carry, so the stack is the
Carrier, the Rider, the Rescued, and the Rescued's own Rider when the Rescued
is a Shared Body. An Unpaired Player rescues a passed-out Shared Body with the
game's carry as it is, its Rider still on it.

## Considered Options

- The Carrier holding two people, the Rider on the back and the Rescued
  elsewhere: the game has one carry per character and no pose for a second
  body, so it would need a carry of the mod's own.
- Setting the Rider down for the rescue: breaks the Pair's carry, which the mod
  holds for the whole Run (ADR 0002).

## Consequences

- The game pauses the Rescued's time for any carrier, so stacking on the Rider
  needs nothing new for the timer.
- The game puts a carry's weight on the carrier, here the Rider, whose statuses
  stay clear; the mod puts it on the Shared Body instead. The Rescued always
  weighs as in unmodded PEAK; Carry Weight still governs only the Pair's own
  Rider.
- The game sets a carried body down when its carrier passes out or dies, but
  here the Rider is awake: the mod sets the Rescued down when the Shared Body
  does, and before its Pair changes.
- A Shared Body carries one Rescued and the Rescued rescues nobody, so a stack
  is at most four scouts.
- An Unmodded Player's game cannot keep such a stack, so a Pair member it picks
  up is still set down by the Troop Leader.
