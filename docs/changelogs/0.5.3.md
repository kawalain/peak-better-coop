# 0.5.3

2026-11-09

Hardening before the first release. Everyone in the room needs 0.5.3.

## Changed

- Verbose Log is off by default; turn it on to report a problem.

## Fixed

- The Rider's HUD counts down candles, lanterns, the magic bugle, rope spools,
  and jetpacks.
- The Rider sees the anti-gravity bubble.
- The Rider's scroll on a rope spool is no longer lost.
- Countdowns and timeouts survive the server clock wrapping.
- Only the Troop Leader can re-attach the Pairs.
- An exception in the mod stays inside the mod instead of stopping the game or
  other mods, and the backpack wheel folds instead of failing another mod's
  patch.
