# 0.4.0

2026-11-09

The mod is now BetterCoop, and the Rider shares the Carrier's view. Everyone
in the room needs 0.4.0.

## Breaking changes

- The mod's id is now `in.kawala.bettercoop`: remove earlier builds, and set
  the options again in `in.kawala.bettercoop.cfg`.
- Timed Shuffle Interval is a whole number of minutes (1 to 60, default 10)
  instead of a preset.

## New

- **Shared View**: the Rider sees the Shared Body as the Carrier does, with the
  Carrier's crosshair, throw bar, rope gauge, and placement previews, and hears
  the Shared Body's item sounds.
- The Rider's progress bar moves smoothly between updates.

## Fixed

- Every Pair changes on a shuffle; two players no longer keep the same Pair
  half the time.
- The Rider sees no injury effect when the Carrier's weight rises.
- Swap Places no longer looks disabled after a click.
