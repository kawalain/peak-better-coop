# 0.2.2

2026-11-08

Pairing, Control Split, and carry weight fixes. Everyone in the room needs
0.2.2.

## Changed

- Korean notices use the game's own words for the Run, the Troop Leader, and
  the backpack.

## Fixed

- The Control Split restarts cleanly when characters respawn on a new scene.
- Two players leaving at once no longer revive a dissolved Pair.
- An unknown Role Preference counts as Random instead of breaking the pairing.
- With an odd count, a player with an oversubscribed Role Preference can be
  the one left Unpaired, so a would-be Carrier is no longer forced to ride.
- The Rider's scroll presses each count, clicks made while the Carrier's menu
  is open are dropped instead of replayed in a burst, and clicks aim along
  the look the Rider sent.
- The Shared Body turns the short way after the game turns it.
- With Carry Weight off, an overloaded Carrier weighs exactly as if carrying
  nobody.
