# 0.2.0

2026-11-08

The first BetterCoop test build, grown from Co-op Mod: a Pair climbs as one
Shared Body. Everyone in the room needs 0.2.0.

## New

- **Pairs**: the Troop Leader pairs the party once per Run. The Carrier
  carries the Rider for the whole Run, and the carry cannot be dropped.
- **Control Split**: the Carrier drives the Shared Body with the keyboard and
  the Rider aims it with the mouse.
- The Rider sees through the Carrier's eyes, with the Carrier's slots,
  stamina, and statuses on their HUD.
- **Shared Life**: a Pair dies and is revived together.
- The party departs only with an even number of players, unless the Troop
  Leader allows an odd one.
- Run Rules (odd player count, carry weight) come from the Troop Leader;
  each player sets a Role Preference.
- The Troop Leader presses F8 to re-attach every Pair.
- After a game update the mod no longer fits, it turns itself off instead of
  half-working.
